# SpicyPrinter

Windows x64 print agent for Spicy restaurant applications.

Download the versioned installer from [Releases](https://github.com/SpicyDevelopment/SpicyPrinter/releases). Pairing with an authorized restaurant application is required; downloading does not grant access to any restaurant.

The current installer is an unsigned test release. Windows may warn or block execution. Do not disable Windows security checks.

Derived from mahmoudps/terminal-printer (MIT). License and attribution are included in the installed application archive.
